About

以运维开发为主线，持续推进企业运维与 Agent 自动化实践。

我目前从事企业运维与运维开发相关工作，主要参与云服务器部署、系统维护优化、监控告警处理、脚本开发和自动化提效，并持续探索 ChatGPT、Codex、Dify 等工具在实际运维与 Agent 工作流中的应用。

职业定位

职业方向包括运维工程师、运维开发与 Agent 开发，围绕 Linux、阿里云、Zabbix、Python / Shell、Docker、Kubernetes、影刀 RPA、Dify 与 AI 工具协作持续积累。已取得阿里云 ACP 云计算认证与影刀 RPA 高级认证。

为什么搭建这个网站

这个网站用于集中展示企业运维开发与自动化实践：从 Linux 和阿里云环境部署、Zabbix 监控告警，到 Python / Shell 脚本、影刀 RPA、Dify 工作流以及 ChatGPT、Codex 辅助开发。每个项目尽量保留实际架构、实施步骤、验证结果和运行记录。
