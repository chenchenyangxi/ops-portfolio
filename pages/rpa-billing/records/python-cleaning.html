数据清洗阶段

Python 清洗与字段标准化

目标
把账单 CSV 转成字段顺序稳定、空值表达明确、可直接交给批量写库组件的数据结构。

1. 为什么不把 CSV 直接写库

账单文件会遇到中文编码、表头字符、空字符串和列顺序变化。只靠 RPA 逐列处理会让流程维护成本升高，因此在写库前加入 Python 清洗层。

2. 清洗层承担的职责

文件读取

兼容常见 CSV 编码，也为 Excel 格式留出读取空间。

字段标准化

固定字段顺序，避免源文件列顺序变化导致数据库字段错位。

空值处理

把空字符串转换成更适合写库的空值表达。

批次补充

补充批次时间、入库创建时间和业务维度字段。

3. 数据结构约束

当前账单清洗后输出二维列表，供批量写库组件消费。字段约束保持清晰，后面写库时才容易核对。

CSV 原始字段：40 列
Python 追加字段：3 列
批量入库字段：43 列

4. 阶段验证

检查点验证方法
路径输入确认传入的是完整 CSV 路径
行数打印清洗后数据长度，不打印整批大对象
列数抽查每行字段数与写库字段数一致
关键字段核对月份、批次和业务维度字段已补齐
经验
RPA 适合流程编排，Python 适合把不稳定表格输入变成稳定数据结构。
