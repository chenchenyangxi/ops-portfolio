本地开发环境

Windows 环境准备

目标
在 Windows 本地建立可重复执行的 Python 运行环境，为后续 Zabbix API 调试、AI 接入和钉钉推送开发提供隔离环境。

1. Python 与 pip 基础验证

项目开始前先确认本机具备 Python 与 pip 能力，避免后续脚本执行时因环境问题报错。

python --version
pip --version

这一阶段的重点不是业务逻辑，而是先把开发环境准备好，让后面的 API 调试、模型测试和推送验证都能在统一环境中执行。

2. 创建项目目录与虚拟环境

在 D:\myserver 目录中创建 Python 虚拟环境，通过项目隔离的方式安装依赖，避免污染系统 Python。

cd D:\myserver
python -m venv .venv
.\.venv\Scripts\Activate.ps1

3. 处理 PowerShell 执行策略

如果 PowerShell 默认策略阻止脚本激活，会出现 PSSecurityException。这里采用当前会话临时放开的方式，不修改系统全局策略。

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1

4. 安装项目依赖

当前项目核心依赖较少，主要是 HTTP 请求与环境变量读取相关组件，保持脚本简单可迁移。

pip install requests python-dotenv

5. 阶段结果

完成这一步后，本地终端已经具备稳定的 Python 运行环境，后续所有脚本都可以在 .venv 中调试和执行，为项目后面的 API 取数、AI 联调和消息推送奠定基础。

本阶段成果
完成 Windows 本地 Python 运行环境、虚拟环境与依赖安装准备，具备继续开展 API 调试和脚本开发的基础条件。
