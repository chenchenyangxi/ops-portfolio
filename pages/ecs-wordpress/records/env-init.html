基础环境

环境准备

目标
在阿里云 ECS 的 Debian 环境中完成系统更新和基础工具安装，为后续 XAMPP 下载、WordPress 解压、端口检查和服务排障提供稳定前置条件。

1. 明确服务器前置条件

这一阶段先确认云主机具备公网访问能力、足够的磁盘空间以及 root 或 sudo 权限。官网部署虽然不是复杂平台项目，但如果基础环境不稳，后续安装包下载、服务启动和目录修改都会频繁出问题。

2. 更新系统软件源

优先把系统软件源和已安装软件更新到较新的稳定状态，减少依赖兼容问题。

sudo apt update
sudo apt upgrade -y

3. 安装常用工具

结合手册中的实际操作，至少准备 wget、curl、net-tools 和 unzip，这些工具会贯穿安装、联通性检查和压缩包处理全过程。

sudo apt install -y wget curl net-tools unzip

4. 预留网络与安全组条件

在正式安装服务前，同步检查云平台安全组和系统防火墙策略，至少保证 HTTP 访问和后续需要的管理端口可以按计划开放。这里不直接在项目页中展示具体公网地址和规则细节，而是保留“已完成联通性准备”的过程表达。

5. 这一阶段为什么重要

官网项目和实验环境不同，后面还会牵涉到上线合规、证书、正式上线访问等流程。先把 Debian 基础环境整理好，可以让后续安装和排障过程更稳定，也便于后期继续维护。

本阶段成果
完成阿里云 ECS 上 Debian 环境的软件更新、工具安装与基础网络准备，具备进入 XAMPP 和 WordPress 部署阶段的前置条件。
