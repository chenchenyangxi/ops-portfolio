Project Summary

项目摘要

项目目标

在阿里云 ECS 上部署企业官网运行环境，完成 WordPress 上线和访问验证。

核心技术栈

阿里云 ECS、Debian、XAMPP、Apache、MySQL、PHP、WordPress。

本人职责

负责服务器初始化、Web 服务部署、数据库配置、域名访问、权限优化与故障排查。

关键成果

完成 1 台 ECS 和 5 个实施阶段的部署验证；项目已完成实施并运行正常。

项目背景

公司需要搭建一个可公网访问的官网，用于对外展示基础信息和业务内容。项目不仅要完成服务器环境和站点程序部署，还要兼顾访问方式、文件权限、服务稳定性以及上线前的上线合规配合工作。

项目目标

在阿里云 ECS 上完成 Debian/Linux 环境下的网站部署，基于 XAMPP 搭建 Apache、MySQL、PHP 运行环境，完成 WordPress 安装、域名解析与访问验证，并为上线合规和后续 HTTPS 配置预留条件。

我负责的工作

负责阿里云 ECS 服务器环境准备、Debian/Linux 基础检查、XAMPP 安装与 Apache / MySQL 服务状态验证、WordPress 下载与初始化配置、数据库创建和授权、域名解析与访问验证、目录权限优化、服务异常排查，并协助推进上线合规配合和后续 HTTPS 准备。

上线验证

检查 Apache、MySQL 服务状态，通过域名访问 WordPress 前台与后台，并记录目录权限和异常处理过程。
