Project Detail

Kubernetes + Prometheus/Grafana 平台实践项目

该项目为个人实验环境实践，用于沉淀 Kubernetes 集群搭建、服务暴露、高可用验证、MySQL 主从和 Prometheus/Grafana 监控可视化经验，不包装成生产级平台。关键步骤已整理为站内项目记录，方便后续复盘、展示和维护。

Linux Docker Kubernetes YAML Nginx Keepalived MySQL Prometheus Grafana
查看搭建记录 返回项目列表

项目定位

个人实验环境中的平台搭建与运维验证项目，重点体现 Kubernetes Master/Node 集群部署、服务暴露、高可用验证、MySQL 主从、Prometheus/Grafana 监控可视化和过程文档化能力，不作为生产级平台包装。

项目背景

为了验证容器平台从节点准备、集群部署到服务运行和监控可视化的完整链路，我在实验环境中搭建 Kubernetes Master + Node 节点，并补充 Keepalived、Nginx、MySQL 主从、Prometheus、Grafana 等组件，沉淀个人实验环境中的平台实践经验。

我的工作内容

完成基础节点初始化、Master 控制平面部署、Node 节点加入、Flannel 网络配置，并配置 Keepalived + Nginx 入口、MySQL 服务、Prometheus + Grafana 监控面板；同时整理命令、截图和问题处理过程，沉淀为可阅读的项目记录。

Architecture

架构说明

这一部分梳理 K8s 架构分层内容，突出组件关系、访问链路和运维验证重点。

基础设施层

CentOS 7.5 1804
静态 IP、关闭 SELinux / 防火墙、时间同步
Docker 20.10
作为容器运行环境
Flannel
用于 Pod 网络通信

K8s 集群应用层

k8smaster
Control Plane / apiserver / etcd / scheduler
k8snode1 / k8snode2
Worker 节点运行测试服务
Tomcat Service
通过 NodePort 验证服务访问

高可用与访问层

Nginx
反向代理与访问入口
Keepalived
VIP 漂移与节点存活检查
Tomcat
用于验证应用发布链路

数据与监控层

MySQL 5.7
主从同步与 Keepalived 高可用验证
Prometheus
K8s、节点与 MySQL 指标采集
Grafana
监控面板与可视化展示
